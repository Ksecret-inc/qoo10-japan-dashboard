# 큐텐 매출 대시보드 (일본 사업팀)

Qoo10 Japan 매출을 한눈에 보는 대시보드입니다. Google Sheets **‘큐텐 매출 자동집계’**를 브라우저에서 직접 읽기 때문에, 시트가 매일 아침 자동 갱신되면 대시보드도 따로 손대지 않아도 최신 숫자를 보여줍니다. 노션 페이지에 임베드해서 쓰는 것을 전제로 만들었습니다.

- 단일 파일: `index.html` (외부 라이브러리 없음, 폰트만 Pretendard CDN)
- 호스팅: GitHub Pages
- 데이터: 시트의 `일별매출` · `SKU별판매` · `바코드결산` 탭, 그리고 `대시보드` 탭 A2 셀(기준일·갱신 시각)

## 화면 구성

| 탭 | 주소 | 내용 |
|---|---|---|
| 요약 | `#summary` | 한 줄 요약, 핵심 지표(이번 달 / 최근 7일 / 최근 30일, 직전 기간 대비), 일별 매출 차트, 월별 실적, 데이터 점검 |
| 상품별 판매 | `#products` | 큐텐 판매 상품(세트 단위)별 수량·매출·비중 — 어제 / 7일 / 30일 / 이번 달 / 전체 |
| 바코드 결산 | `#barcode` | 월을 골라 낱개 바코드별 수량·금액(참고), 결산용 A~G열 복사, 바코드×월 수량표 |

주소 끝의 `#barcode`처럼 탭을 지정하면 그 탭이 열린 채로 임베드됩니다. 예를 들어 결산 페이지에는 `…/#barcode`만 따로 걸어 둘 수 있습니다.

### 숫자 정의

- **매출**: 주문일(일본 시간) 기준 결제금액. `일별매출` 탭의 `매출(엔)`.
- **객단가**: 매출 ÷ 주문건수.
- **이번 달 비교**: 이번 달 1일~기준일 vs 전월 같은 날짜 구간 (시트의 대시보드 탭과 같은 방식).
- **0엔 주문 포함 추정일**: 주문 50건 이상이면서 객단가 ¥500 미만인 날. 증정·체험 등 0엔 주문이 배송완료로 잡힌 날이라 주문건수·객단가가 부풀려지고, 바코드 결산 수량에는 무상 출고분으로 포함됩니다. 기준값은 `index.html` 상단 `ZERO_YEN_AOV`, `ZERO_YEN_MIN_ORDERS`에서 바꿀 수 있습니다.
- **바코드별 금액**: 세트 매출을 낱개 수량 비율로 나눈 참고값입니다. 월 매출 합계는 `Total R`(그날 실제 결제금액)의 합입니다.

### 데이터 점검 항목

요약 탭 하단에 자동으로 표시됩니다.

- 0엔 주문 포함 추정일
- 바코드 미등록 상품 (`상품명매핑` 시트 I열 ‘바코드 구성’이 비어 있는 상품)
- 월별 `바코드결산` Total R 합계 ≠ `일별매출` 합계
- 시트가 36시간 넘게 갱신되지 않음

## 처음 설정 (한 번만)

1. **시트 공유**: ‘큐텐 매출 자동집계’ → 공유 → 일반 액세스를 **링크가 있는 모든 사용자 · 뷰어**로 바꿉니다. 대시보드는 로그인 없이 시트를 읽기 때문에 이 설정이 없으면 “시트를 읽지 못했습니다”가 뜹니다.
2. **GitHub Pages**: 이 레포 Settings → Pages → Branch `main`, 폴더 `/ (root)` → Save. 1~2분 뒤 `https://ksecret-inc.github.io/qoo10-japan-dashboard/` 에서 열립니다.
3. **노션 임베드**: 노션 페이지에서 `/임베드`(`/embed`) → 위 주소를 붙여넣고 높이를 조절합니다. 탭 하나만 넣으려면 주소 끝에 `#products`, `#barcode`를 붙입니다.

> **공개 범위 주의**: 이 레포와 GitHub Pages 주소는 공개입니다. 시트 ID가 코드에 들어 있으므로, 링크 공유가 켜져 있는 동안에는 이 코드를 본 사람은 누구나 시트를 열람할 수 있습니다. 주문 원장까지 포함된 시트라는 점을 감안해, 필요하면 집계 탭만 별도 시트로 분리하는 방식으로 바꾸세요.

## 시트 구조가 바뀌면

열은 **머리글 이름**으로 찾습니다. 열 순서가 바뀌어도 동작하지만, 아래 머리글 이름이나 탭 이름이 바뀌면 화면 상단에 어느 탭의 어느 열을 못 찾았는지 표시됩니다. 그때는 `index.html`의 `SOURCES`(탭 이름)와 `SPEC`(머리글 이름)을 고치면 됩니다.

| 탭 | 사용하는 머리글 |
|---|---|
| 일별매출 | 날짜, 매출(엔), 주문건수, 판매수량, 정산예정(엔) |
| SKU별판매 | 상품명, 상품코드, 어제/최근 7일/최근 30일/이번 달/전체 수량, 같은 기간 매출 |
| 바코드결산 | Y, M, D, Company, Barcode, Q, Total R, 바코드별 금액(엔, 참고), 상품명(참고) |
| 대시보드 | A2 셀의 “기준: YYYY-MM-DD … 갱신 YYYY-MM-DD HH:MM” 문구 |

다른 시트를 보게 하려면 `index.html` 상단의 `SHEET_ID`를 바꿉니다.

## 로컬에서 보기

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 을 엽니다. (시트 링크 공유가 켜져 있어야 데이터가 나옵니다.)
